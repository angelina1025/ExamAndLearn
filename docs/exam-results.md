# 考試結果功能與整合說明

## 開發與整合

- 技術：Next.js App Router、React、TypeScript。
- 開發分支：`考試結果`，已合併本機 `管理員介面` 作為基礎。
- 最終 PR：來源 `考試結果`，目標 `管理員介面`。尚未推送或執行最終合併。
- 目前結果使用本機儲存，並非正式後端成績系統；不要用於高風險正式考試。

## 五項功能

1. 成績：總分、滿分、總題數、答對、答錯、未作答、正確率。
2. 詳解：題幹、全部選項、考生選擇、標準答案、配分與解析。
3. 篩選：全部／錯題／未作答，可搭配學科與難度，支援清除條件。
4. 匯出：真正的 Excel `.xlsx`，或經 Google OAuth 授權建立新 Google 試算表。
5. 分析：學科與難度分組的題數、答對、答錯、未作答與正確率。

錯題篩選和匯出包含答錯及未作答；已作答但缺標準答案的題目不直接判錯。
多選答案忽略順序、大小寫與重複項目，必須完全符合才給分；不修改原始作答陣列。
缺少學科、難度、答案與解析時顯示明確提示，不捏造內容。
分析固定使用整份試卷，題目篩選不會改寫分析統計。

## 結果頁與資料契約

- 原考試交卷後顯示結果摘要，點「查看逐題詳解與分析」展開所有功能。
- 「開啟獨立結果頁」連往 `/exam/result/<UUID>`，預設展開。
- 快照 key：`exam-result:v1:<UUID>`，保存考卷、作答、交卷時間與自動交卷標記。
- 快照僅在原瀏覽器可用；重新整理可還原，但跨裝置、清除網站資料後無法還原。
- 本機儲存不可用時，仍顯示當次結果，但提示先下載錯題，不提供無效的結果連結。
- `ExamQuestion` 新增選填的 `subjectId`、`subjectName`、`difficulty`；不要求其他分支立刻修改。
- `getAssignedExam` 保留題庫的答案、解析、學科與難度；示範考卷也從既有題庫補齊答案。

## Google Sheets

沿用既有 Firebase Google 登入與記憶體 access token，不將 token 寫入 localStorage。
點匯出前須同意 Google 授權；已有有效 token 時沿用。
Firebase 專案需設定 Google 登入、允許本機網域，並啟用 Google Sheets API。
匯出會透過 Google Sheets API 在使用者帳號建立新的試算表，不覆寫管理員公用題庫。
僅在 Google API 成功回應後顯示連結；授權過期、權限不足或網路失敗顯示錯誤。
Google 使用 `stringValue`、Excel 使用字串儲存題目，避免題目內容被解析為公式。

## 啟動與驗證

```sh
npm ci
npm run dev
npm run lint
npm test
```

基礎分支已追蹤 `.next` 建置產物；本功能沒有刪除這些既有檔案。
如需驗證建置而不覆蓋它們，可以使用獨立輸出目錄：

```sh
NEXT_DIST_DIR=.next-results npm run build
```

手動驗收：從 `/exam/assigned-demo` 作答數題並交卷，展開詳解、切換錯題及篩選、
下載 Excel、開啟獨立結果頁後重新整理，再以真實 Google 帳號測試授權和匯出。
Google 真實寫入需人工授權；自動化測試使用 API mock，不寫入任何使用者雲端資料。
