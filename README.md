# ExamAndLearn

線上測驗與學習平台。

# 使用語言

Next.js

## 專案功能

- 首頁顯示已接收的自組考卷
- 50 題單選模擬考卷（60 分鐘）
- 倒數計時、標註、題目地圖、上一題／下一題
- 暫停／繼續、手動交卷、時間到自動交卷
- 以 localStorage 保留作答進度與標註

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 常用指令

```bash
npm test -- --run   # 執行測試
npm run typecheck   # 型別檢查
npm run lint        # ESLint
npm run build       # 生產環境建置
```
